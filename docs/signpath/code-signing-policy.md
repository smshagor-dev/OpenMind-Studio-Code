# Code signing policy — text for the home and download pages

SignPath Foundation requires a "Code signing policy" section on the project's home page and download page
([signpath.org/terms](https://signpath.org/terms)). The source repository's README carries it (marked pending). Put
the block below into the **public release repository's** README (`smshagor-dev/OpenMind-Studio`) as well — only the
"pending" sentence changes after approval.

---

## Code signing policy

Free code signing provided by [SignPath.io](https://about.signpath.io), certificate by
[SignPath Foundation](https://signpath.org).
*(Until the application is approved: "Windows code signing through SignPath Foundation has been applied for; current
Windows downloads are not Authenticode-signed.")*

Windows files are built by GitHub Actions from the public source repository
[smshagor-dev/OpenMind-Studio-Code](https://github.com/smshagor-dev/OpenMind-Studio-Code) (branch `main`) and every
release is approved by hand before it is signed.

**Privacy policy:** This program will not transfer any information to other networked systems unless specifically
requested by the user or the person installing or operating it, except two automatic requests: the update check to
GitHub, and the Open VSX marketplace list while the Extensions view is shown (can be turned off). Details:
[PRIVACY.md](https://github.com/smshagor-dev/OpenMind-Studio-Code/blob/main/docs/legal/privacy-policy.md).
